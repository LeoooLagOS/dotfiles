# _Programming Languages_

## 📝 One-Sentence Summary
A programming language is a formal system of instructions and syntax used to communicate with a computer, allowing a programmer to write code that the machine can execute to perform a specific task.

## 💡 Analogy
Programming languages are like different types of **blueprints for building a house**. 
- A **low-level language** (like [[_C|C]]) is a highly detailed, technical blueprint showing every wire, pipe, and screw. It's powerful and precise but complex to write. 
- A **high-level language** (like [[_Python|Python]]) is a more abstract blueprint focusing on the room layout and function ("living room here, kitchen there"). It's much easier to read and write but hides the underlying construction details.
## 📜 History & Creator
The history of programming languages is an evolution from machine-level instructions to human-readable abstractions. Key milestones include: 
- **1950s:** The first major high-level languages emerged, including **Fortran** for scientific computing and **COBOL** for business applications. 
- **1970s:** The era of structured programming, defined by influential languages like **Pascal** and, most importantly, **[[_C|C]]**, which was used to write the Unix operating system. 
- **1980s-90s:** The [[Object-Oriented Programming]] boom, led by **C++** and then **[[_Java|Java]]**, which introduced platform independence. 
- **1990s-Present:** The rise of scripting and dynamic languages like **[[_Python|Python]]** and **JavaScript**, focusing on developer productivity and specialized domains like web development and data science.

## 🔑 Core Philosophy & Design 
Languages are designed around a series of trade-offs and philosophies that determine how they are used. 
- **Level of Abstraction:** 
	- How much of the underlying hardware is hidden from the programmer? Low-level languages offer more control, while high-level languages offer more safety and ease of use. 
- **Programming Paradigms:** 
	- The style of programming a language encourages. Common paradigms include **procedural** (a series of steps), **object-oriented** (modeling the world as objects), and **functional** (treating computation as the evaluation of mathematical functions). 
- **Typing System:** 
	- The rules for how a language handles data types, most notably the distinction between [[Static vs Dynamic Typing]].

## ⚙️ Key Details 
- **What it is:** 
	- A formal language with strict rules for syntax (grammar) and semantics (meaning). 
- **Why it exists:** 
	- To bridge the enormous conceptual gap between human logic and the binary instructions a computer's [[CPU]] understands. 
- **Core Components:** 
	- **Syntax:** The grammatical rules for how to write valid code. 
	- **Semantics:** The meaning of the instructions. 
	- **[[Compiler / Interpreter]]:** The program that translates the human-readable code into machine-executable instructions.
## 🔗 Connections & Implementations
Programming languages are the primary tool for implementing all other computer science concepts. 
- **Specific Implementations:** 
	- [[_C]] - A low-level, procedural language. 
	- [[_Java]] - A statically-typed, object-oriented language. 
	- [[_Python]] - A dynamically-typed, multi-paradigm language. 
- **Core Concepts:** 
	- Languages are used to implement [[Algorithms]] and [[Data Structures]].
