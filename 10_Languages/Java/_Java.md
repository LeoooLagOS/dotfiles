# _Java_

## 📝 One-Sentence Summary
Java is a high-level, class-based, [[object-oriented programming]] language designed for platform independence via the [[Java Virtual Machine (JVM)]].

## 💡 Core Philosophy
"**Write Once, Run Anywhere**" (WORA). The goal is to write code on one platform and have it run on any other platform that has a JVM, without needing to be recompiled for each.

## 🔑 Key Details
- **Execution:** 
	- Code is **compiled** into an intermediate "bytecode," which is then interpreted and executed by the **[[Java Virtual Machine (JVM)]]**. 
- **Typing:** 
	- A **[[Static vs Dynamic Typing|statically-typed]]** language, where you must declare the data type of every variable. This allows the compiler to catch many errors early. 
- **Memory:** 
	- Uses a sophisticated, automatic [[Garbage Collection|Garbage Collector]]. 
- **Paradigm:** 
	- Strongly **object-oriented**, where almost everything is an object.
## 🚀 Primary Use Cases 
- **Enterprise-Scale Applications:** 
	- Its robustness, security, and scalability make it a top choice for large, backend systems (often using the Spring Framework). 
- **Android Mobile Development:** 
	- The original official language for Android. 
- **Big Data Applications:** 
	- Many major big data frameworks, like Hadoop and Spark, are written in Java.
## 👍 Pros & 👎 Cons
- **✅ Strengths:** 
	- Excellent performance, platform independence (thanks to the JVM), very robust and secure, and a massive ecosystem for large-scale development. 
- **❌ Weaknesses:** 
	- Can be more "verbose" (require more lines of code) than Python for simple tasks. JVM startup time can be slow for small applications.
