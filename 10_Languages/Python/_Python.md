# _Python_

## 📝 One-Sentence Summary
Python is a high-level, interpreted programming language known for its emphasis on code readability, simplicity, and developer productivity.

## 💡 Core Philosophy
"**The Zen of Python**" guides its design, prioritizing principles like "Beautiful is better than ugly," and "Simple is better than complex." 
The goal is to allow developers to express concepts in fewer lines of code than would be possible in languages like C++ or Java.

## 📜 History & Creator 
Python was created by **Guido van Rossum** and first released in 1991. He began working on it in the late 1980s as a successor to the ABC language, wanting to create a language that was easy to read and highly extensible. 
The name was famously inspired by the British comedy group Monty Python's Flying Circus.

## 🔑 Key Characteristics
- **Execution:** 
	- An **interpreted** language, executed line-by-line, which simplifies debugging. 
- **Typing:** 
	- A **[[Static vs Dynamic Typing|dynamically-typed]]** language, where variable types are determined at runtime. 
- **Memory:** 
	- Features automatic [[Memory Management]] via a [[Garbage Collection|Garbage Collector]]. 
- **Paradigm:** 
	- A **multi-paradigm** language supporting object-oriented, procedural, and functional styles.

## 🚀 Primary Use Cases 
- **Data Science & Machine Learning:** 
	- Python's dominant field, with essential libraries like NumPy, Pandas, TensorFlow, and PyTorch. 
- **Web Development:** 
	- Backend development with popular frameworks like Django and Flask. 
- **Scripting & Automation:** 
	- A go-to language for automating tasks due to its simple syntax.
## 👍 Pros & 👎 Cons
- **✅ Strengths:** 
	- Extremely easy to learn and read, massive ecosystem of third-party libraries, and a very large, active community. 
- **❌ Weaknesses:** 
	- Slower performance compared to compiled languages, and not a primary choice for mobile app development.
