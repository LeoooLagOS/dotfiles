# Class 04: Intro to Weka and KDD Framework

## 🎯 Main Goal of Today
Understand the operational environment of Weka and the theoretical workflow of Knowledge Discovery in Databases (KDD).

## 📓 Lecture Summary
- **Weka Environment:** - An open-source suite developed in **Java**.
	- Specialized in data classification and visualization.
	- Features "Out of the box" algorithms including Decision Trees and Clustering tools.
- **KDD (Knowledge Discovery in Databases):**
	- The overarching process of turning raw data into actionable knowledge.
	- Data Mining is identified as a specific step *within* this broader framework.

## 🛠️ Logic Flow: The KDD Scheme
The lecture outlined the following pipeline for data transformation:
1. **Raw Data:** The initial input (Database, CSV, etc.).
2. **Preprocessing:** Cleaning noise and handling missing values.
3. **Data Warehouse:** Centralized storage for integrated data.
4. **Data Mining:** Application of algorithms (e.g., [[SimpleKMeans]]).
5. **Evaluation/Interpretation:** Transforming patterns into human-readable Knowledge.
