# Programming Paradigms

## 📝 One-Sentence Summary
A programming paradigm is a fundamental style, philosophy, or "way of thinking" about how to structure and write computer programs.
## 💡 Analogy
Paradigms are like different **architectural styles for building a house**. 
- **[[Procedural Programming]]** is like a **traditional blueprint**, with a detailed, step-by-step plan for each room. 
- **[[Object-Oriented Programming]]** is like using **pre-fabricated modules**. You have self-contained kitchens and bathrooms (objects) that you connect to build the house. 
- **[[Functional Programming]]** is like a **modern, minimalist design** that focuses on the flow of energy and light through the house, using a series of transformations.
## 🔑 Key Details
- **What it is:** 
	- A set of principles and concepts that defines a way to build software. Most modern languages are **multi-paradigm**, allowing the programmer to mix and match styles. 
- **Why it exists:** 
	- Different paradigms are better suited for solving different types of problems. Choosing the right paradigm can make code simpler, more scalable, and easier to reason about.
