# Object-Oriented Programming

## 📝 One-Sentence Summary
A programming paradigm based on the concept of "objects," which bundle data (attributes) and the methods (functions) that operate on that data into a single, self-contained unit.
## 💡 Analogy
OOP is like building with **Lego bricks**. Each brick (object) is a self-contained unit with its own properties (color, shape) and built-in functionality (how it connects to other bricks). You combine these standardized bricks to build a complex structure.
## 🔑 Key Details
- **Core Idea:** 
	- To organize software by modeling real-world entities as objects. Data and the functions that modify that data are bundled together. 
- **The Four Pillars of OOP:** 
	- [[Encapsulation]]: 
		- Bundling data and methods together, hiding the internal complexity. 
	- [[Abstraction]]: 
		- Exposing only the essential features of an object. 
	- [[Inheritance]]: 
		- Allowing a new class (child) to take on the properties and methods of an existing class (parent). 
	- [[Polymorphism]]: 
		- Allowing an object to take on many forms, most commonly through method overriding.
## 🔗 Connections & Implementations
- [[_Java]] is a strongly object-oriented language. 
- [[_Python]] is a multi-paradigm language with strong support for OOP.
