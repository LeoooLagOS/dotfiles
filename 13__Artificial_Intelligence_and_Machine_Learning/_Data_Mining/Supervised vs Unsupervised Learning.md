# Supervised vs Unsupervised Learning

## 📝 One-Sentence Summary
The distinction between learning models that map inputs to known outputs (Supervised) and those that identify hidden structures in unlabeled data (Unsupervised).

## 💡 Analogy
**Supervised Learning** is like a student with an answer key; they check their work against known results. **Unsupervised Learning** is like an explorer in a new land; they group things by how similar they look without knowing their names.

## 🔑 Key Details
- **Supervised Learning:**
	- **Regression:** Predicts continuous/quantitative values (e.g., house prices).
	- **Classification:** Predicts qualitative/categorical labels (e.g., spam vs. not spam).
- **Unsupervised Learning:**
	- **Clustering:** Groups data based on inherent similarities without a target variable.

## 🔗 Connections & Implementations
- Implementation:** Linear Regression is a primary tool for quantitative prediction.
- **Workflow:** This distinction determines the step in the [[CRISP-DM Process]] or [[KDD Process]].
