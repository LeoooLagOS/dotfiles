# Procedural Programming

## 📝 One-Sentence Summary
A programming paradigm based on the concept of the "procedure call," where programs are structured as a sequence of procedures (or functions) that operate on data.
## 💡 Analogy
Procedural programming is like following a **detailed, step-by-step recipe** to bake a cake. You follow the instructions in a specific order, from top to bottom, to get the final result.
## 🔑 Key Details
- **Core Idea:** 
	- The program is a series of sequential steps. Data and the procedures that operate on that data are kept separate. 
- **Structure:** 
	- Code is organized into procedures (also known as functions, routines, or subroutines). 
- **State:** 
	- Tends to use shared, mutable state, where procedures modify global or shared variables.
## 🔗 Connections & Implementations
- [[_C]] is the quintessential procedural language. 
- It is the historical foundation upon which [[Object-Oriented Programming]] was built.
