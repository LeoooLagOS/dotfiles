# Petri Nets

## 📝 One-Sentence Summary
A mathematical modeling language for the description of distributed systems using places (states), transitions (actions), and tokens (flow).

## 💡 Analogy
A board game where pieces (Tokens) move between circles (Places) only when certain conditions (Transitions) are met.

## 🔑 Key Details
- **What it is:** A graphical and mathematical tool for modeling concurrency.
- **Why it exists:** To detect deadlocks and race conditions before writing code.
- **Tools:** **PIPE V4** is the primary software mentioned for modeling these nets.
