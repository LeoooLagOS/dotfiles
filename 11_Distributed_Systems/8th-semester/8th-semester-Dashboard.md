# 🎓 Applied Distributive Programming - Course Dashboard

## 🗓️ Class 01 Recap (2026-01-07)
**Key Focus:** Introduction to Network Communication & Protocols.

### 📝 Core Concepts Covered
- **Communication Models:** 1:1 (Unicast), 1:N (Multicast/Broadcast), N:N (Mesh).
- **Physical Standards:** RS232 (Crossover wiring: TxD -> RxD, DTR -> DSR).
- **Hardware Parameters:** - 9600 baud (30m) vs. 300 baud (300m).
	- Stop and Wait flow control.
- **Middleware & Agents:** Introduction to RabbitMQ and ROS 2.
- **Protocol Stack:** Modbus, CAN Bus, SNMP (using MIBs), NTCIP.
- **Modeling Tools:** Petri Nets (using PIPE V4).
