# RabbitMQ

## 📝 One-Sentence Summary
An open-source message-broker software that implements the Advanced Message Queuing Protocol ([[AMQP]]) to handle data between applications.

## 💡 Analogy
The Post Office: It accepts mail (Messages), stores it in a sorting facility (Queue), and delivers it to the recipient (Consumer) when they are ready.

## 🔑 Key Details
- **What it is:** A robust message-oriented middleware.
- **Why it exists:** To decouple producers from consumers, allowing for asynchronous communication and handling N to N patterns.
