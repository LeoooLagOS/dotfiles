# 🗂️ config/ — Application configs

Configuration for every desktop application, linked into `~/.config` by the `links` step of `install.sh`. Each directory is linked whole, except `quickshell/`, whose sub-configs are linked one by one so generated files stay local.

| Directory | Linked to | Purpose |
|---|---|---|
| [`hypr/`](hypr/README.md) | `~/.config/hypr` | Hyprland WM: Lua config engine, rules, Rofi, theming |
| `waybar/` | `~/.config/waybar` | Status bar ([below](#-waybar)) |
| `swaync/` | `~/.config/swaync` | Former notification center, replaced by the Quickshell panel ([below](#-swaync)) |
| [`kitty/`](kitty/README.md) | `~/.config/kitty` | GPU-accelerated terminal and its theme library |
| [`quickshell/`](quickshell/README.md) | `~/.config/quickshell/{overview,qs-hyprview,panel}` | Workspace overview, window exposé and side panel |
| [`starship/`](starship/README.md) | `~/.config/starship` | Selectable prompt profiles |
| [`fastfetch/`](fastfetch/README.md) | `~/.config/fastfetch` | System info dashboard shown on shell start |
| `wlogout/` | `~/.config/wlogout` | Icons for the [power menu](#-power-menu) |

Most of these started as [KoolDots](https://github.com/LinuxBeginnings/Hyprland-Dots) configs; `scripts/ops/kooldots-sync` brings in upstream updates (see the [root README](../README.md#-upstream-updates-kooldots)).

## 📊 Waybar

The status bar, from KoolDots.

- `configs/` holds the bar layouts and `style/` the stylesheets. The active ones are the `config` and `style.css` symlinks, switched by `scripts/wm/WaybarLayout.sh` and `scripts/wm/WaybarStyles.sh` (so switching shows up as a change in git).
- `Modules*`, `UserModules` and `ModulesCustom` define the modules the layouts include; `UserModules` is the place for personal ones.
- `wallust/colors-waybar.css` is generated from the wallpaper by Wallust and is git-ignored.
- Reload with `scripts/wm/Refresh.sh`.

Upstream KoolDots has since moved Waybar to `~/.config/hypr/waybar`; until that migration is synced, this directory is the live one.

## 🔔 SwayNC

**Not in use** — notifications are now handled by the [Quickshell panel](quickshell/panel/README.md#notifications). Kept for reference: the notification center and its quick-settings panel, from KoolDots: `config.json` (layout, widgets, buttons), `style.css` and the `icons/` and `images/` it uses. Reload with `swaync-client -R -rs`.

## 🚪 Power menu

The power menu is `scripts/wm/PowerMenu.py`, a GTK layer-shell window that replaced wlogout, which ran an action on the first keypress.

| Key | Action | Trigger |
|---|---|---|
| L | Lock | Tap |
| O | Logout | Hold 500 ms |
| P | Shutdown | Hold 500 ms |
| R | Reboot | Hold 500 ms |
| S | Suspend | Hold 500 ms |
| Esc | Close the menu | Tap |

While a key is held, its tile fills up; releasing early drains it. Holding the left mouse button on a tile works the same way.

- It reuses the icons in `config/wlogout/icons/` and the wallust colors from `config/waybar/wallust/colors-waybar.css`. The `layout` and `style.css` in `config/wlogout/` are no longer used and are kept only for upstream syncs.
- `scripts/wm/Wlogout.sh` toggles the menu open and closed. It keeps its old name because Waybar, swaync and the Ctrl+Alt+P keybind call it.
- The blurred background comes from the `powermenu` layer rule in `config/hypr/UserConfigs/user_layer_rules.lua`.

## 🔎 Rofi menus

All Rofi menus (app launcher, keybind search, clipboard, emoji, wallpapers, quick settings, theme pickers…) live in `config/hypr/rofi/` and use the **Lagos** theme, made to match the [Quickshell panel](quickshell/panel/README.md):

- `themes/Lagos.rasi` — Inter, a card about 760 px wide whose height follows its lines, 22/14/10 px corners, the accent at 20% for the selection.
- **Where menus open**: anchored to the bottom edge (Hyprland slides them up, the default) or floating in the center. `scripts/wm/RofiPosition.sh bottom|center|toggle` writes `position.rasi`, which `Lagos.rasi` imports last; the panel's Settings → Appearance → Menus does the same.
- Colors are the panel's dark palette, generated by Wallust: the `lagos-*` tokens at the end of `config/hypr/wallust/templates/colors-rofi.rasi`.
- `0-shared-fonts.rasi` sets the font; `config.rasi` loads the theme. The Rofi theme picker (Super+Ctrl+R) appends its choice to `config.rasi`, and the last `@theme` wins — delete that line to go back to Lagos.
- **Math in the app launcher**: SUPER D (`scripts/wm/RofiLauncher.sh`) combines Apps with the [quickcalc plugin](../scripts/rofi-quickcalc/README.md), so typing `2+2`, `10 km to mi` or `100 USD to MXN` shows the answer as the first row (Enter copies), and an expression in `x` offers a plot. The Calc tab, and its own window on Super+Alt+C or the Calculator key (`scripts/wm/RofiCalc.sh`), is the full calculator: large result, history, `plot sin(x) -6 6`. Plots (`scripts/wm/CalcPlot.sh`) are gnuplot windows in the wallpaper colors.
- Each `config-*.rasi` only sets one menu's layout (columns, lines, width, placeholder). Messages and placeholders are plain text, without emoji.

## ⌨️ Extra keybinds

Added in `config/hypr/UserConfigs/user_keybinds.lua`; they show up in the keybind search (Super+Shift+K).

| Keys | Action |
|---|---|
| Super+D | App launcher; type math in the search for an instant answer |
| Super+Alt+C · Calculator key | Calculator (history, conversions, plots) |
| Super+Alt+P | Panel settings |
| Super+Alt+G | Panel blur on/off (`scripts/wm/PanelBlur.sh`) |
| Super+Alt+− / = | Panel more transparent / more opaque (`scripts/wm/PanelOpacity.sh`) |
| Super+Alt+W | Colors from the wallpaper on/off (`scripts/wm/WallustToggle.sh`) |
| Super+Alt+I | Caffeine: keep the screen awake |
| Super+Alt+D | Dark / light theme for the whole desktop (`scripts/wm/DarkLight.sh`) |
| Super+Alt+M | Monitor profiles |
| Super+Alt+K | Lock screen wallpaper: by default it follows the desktop wallpaper; picking one pins it, "Same as the desktop" goes back |
| Super+Alt+T | Starship prompt style |
| Super+J | Java versions (install / set default) |
