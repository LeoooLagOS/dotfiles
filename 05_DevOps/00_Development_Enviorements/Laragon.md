# Laragon

## 📝 One-Sentence Summary
Laragon is a portable, isolated, fast, and powerful universal development environment primarily for [[_PHP]], Node.js, [[_Python]], [[_Java]], Go, and Ruby on [[_Windows]].
## 💡 Analogy
Laragon is like a pre-configured **mobile kitchen** for a chef. It comes fully equipped with the stove (web server - Apache/Nginx), ingredients storage (database - MySQL/PostgreSQL), essential tools (PHP, Node.js), and even a recipe assistant (Composer) all packed into one convenient, portable unit. You can start cooking immediately without setting up each piece individually.
## 🔑 Key Details
- **What it is:** 
	- A local server stack application for Windows that simplifies setting up a development environment for various web technologies. 
- **Why it exists:** 
	- To provide a fast, easy-to-use alternative to setting up individual components like Apache, MySQL, and PHP manually, especially on Windows. It isolates the environment, preventing conflicts with other software. 
- **Core Components (Full Edition):** 
	- Includes Apache, Nginx, MySQL, PostgreSQL, PHP, Node.js, npm, Python, Composer, Git, and more.
## 🔗 Connections & Implementations
- It provides the runtime environment (PHP, MySQL server) needed for frameworks like [[Laravel]]. 
- Includes [[Composer]] for PHP package management. 
- Often used with database tools like [[MySQL Workbench]].
## 👍 Pros & 👎 Cons
- **✅ Pros:** 
	- Extremely fast and lightweight compared to alternatives like XAMPP/WAMP. 
	- Easy to switch PHP/MySQL versions. Automatic virtual host creation. Portable. 
- **❌ Cons:** Windows only.
