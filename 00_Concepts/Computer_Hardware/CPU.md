# CPU (Central Processing Unit)

## 📝 One-Sentence Summary 

The CPU is the primary component of a computer that acts as its "brain," performing the calculations and executing the instructions that make the software run. 
## 💡 Analogy 

The CPU is the chef in a kitchen. It takes ingredients (data) and follows a recipe (a program) to produce a final dish (the output). 
## 🔑 Key Details 

- **Function:** It fetches, decodes, and executes instructions from memory. 
- **Role in Booting:** During the [[Switch Boot Sequence]], the CPU is one of the first components checked by the [[POST]] and is then initialized by the boot loader. 
- **Role in Operation:** Once booted, the CPU runs the [[Cisco IOS]] to process network traffic, handle management tasks, and run routing protocols.
