# DRAM (Dynamic Random-Access Memory)

## 📝 One-Sentence Summary 
DRAM is the volatile, high-speed working memory that a device uses to store running applications and their data. 
## 💡 Analogy 

DRAM is like your workbench or desk space. When you work on a project (run a program), you take the tools and materials out of storage (Flash Memory) and place them on your desk (DRAM) where you can access them quickly. When you turn the power off, the desk is cleared. 
## 🔑 Key Details 

- **Volatile:** Its contents are lost when the device loses power. 
- **High-Speed:** It provides the [[CPU]] with fast access to the instructions and data it needs to operate. 
- **Function in a Switch:** The [[Cisco IOS]] operating system is loaded from [[Flash Memory]] into DRAM to be executed. The running configuration file and network data tables (like MAC address tables) are also stored here.
