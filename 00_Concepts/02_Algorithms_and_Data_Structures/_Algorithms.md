# _Algorithms_

## 📝 One-Sentence Summary
An algorithm is a finite, well-defined sequence of computational steps that takes an input, follows a set of rules, and produces an output, solving a specific problem.
## 💡 Analogy
An algorithm is like a **recipe for baking a cake**. 
- **The Input:** The ingredients (flour, sugar, eggs). 
- **The Algorithm:** The step-by-step instructions in the recipe (mix flour and sugar, add eggs, bake at 350°F for 30 minutes). 
- **The Output:** The finished cake. Following the same recipe with the same ingredients will always produce the same cake.

## 📜 History & Creator
The concept of an algorithm is ancient, with early examples like Euclid's algorithm for finding the greatest common divisor.
The modern formalization was pioneered by figures like **Alan Turing** with the Turing machine in the 1930s, which provided a mathematical model of a general-purpose computer. 
The term itself is derived from the name of the 9th-century Persian mathematician, **Muhammad ibn Musa al-Khwarizmi**.
## 🔑 Core Philosophy & Design 
The core philosophy of algorithm design is to create a process that is: 
- **Correct:** It must produce the correct output for all valid inputs. 
- **Efficient:** It should solve the problem using the minimum possible time and memory resources. This is measured with [[Big O Notation]]. 
- **Unambiguous:** Each step must be precisely defined and clear. 
- **Finite:** The algorithm must terminate after a finite number of steps.

## ⚙️ Key Details 
- **What it is:** 
	- A step-by-step procedure for solving a problem. 
- **Why it exists:** 
	- To provide a formal and repeatable method for solving computational problems. 
- **Core Categories & Paradigms:** 
	- **Sorting Algorithms:** (e.g., [[Merge Sort]], [[Quick Sort]]) 
	- **Searching Algorithms:** (e.g., [[Binary Search]]) 
	- **Graph Algorithms:** (e.g., [[Dijkstra's Algorithm]], [[Breadth-First Search (BFS)]]) 
	- **[[Dynamic Programming]]:** Breaking a problem down into simpler, overlapping subproblems. 
	- **Divide and Conquer:** Breaking a problem into smaller, independent subproblems.

## 🔗 Connections & Implementations
- Algorithms are the "verbs" of programming; they operate on [[_Data Structures|Data Structures]] (the "nouns"). 
- The efficiency of an algorithm is analyzed using [[Big O Notation]].
