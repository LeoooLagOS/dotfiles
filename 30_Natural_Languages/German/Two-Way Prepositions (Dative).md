# Two-Way Prepositions (Dative)

## 📝 **One-Sentence Summary**
The nine German two-way prepositions take the [[Dative Case]] when they answer the question "Wo?" (Where?) to describe a static, unchanging location.
## 💡 **Core Rule & Analogy**
**The Rule:** If a two-way preposition describes a static location (triggered by verbs of state like *sein*, *stehen*, *liegen*), the noun that follows must be in the Dative case.
### **Analogy:** 
Think of these prepositions as "context-aware operators." When the context is a query for a static location (`Wo?`), the operator applies the Dative case transformation to its operand (the noun).

## ⚙️ **Syntactical Structure**
The Dative case modifies the article of the noun that follows the preposition.

| Gender                    | Nominative (Base) | Dative (Location) |
| :------------------------ | :---------------- | :---------------- |
| Masculine<br><br><br><br> | der / ein         | **dem / einem**   |
| Feminine                  | die / eine        | **der / einer**   |
|                           |                   |                   |
| Neuter                    | das / ein         | **dem / einem**   |
| Plural                    | die / keine       | **den ...-n**     |

**Common Contractions:** `an + dem = am`, `in + dem = im`.
## 🚀 **Examples in Context**
- **an (on a vertical surface):** Das Bild hängt an **der Wand**. (The picture hangs on the wall.) 
- **auf (on a horizontal surface):** Die Kaffeemaschine steht auf **dem Fensterbrett**. (The coffee machine stands on the windowsill.) 
- **in (in):** Er steht **im Schrank**. (`im` = `in dem`) (He is standing in the closet.) 
- **über (over/above):** Die Lampe hängt über **dem Tisch**. (The lamp hangs over the table.) 
- **zwischen (between):** Das Buch liegt zwischen **den Tassen**. (The book lies between the cups.)

## 🔗 **Connections**
- This is the "location" counterpart to [[Two-Way Prepositions (Accusative)]], which describes direction. 
- It is triggered by verbs of state, such as [[sein (to be)]], [[stehen (to stand)]], and [[liegen (to lie)]].
