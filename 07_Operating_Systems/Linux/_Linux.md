# _Linux_

## 📝 One-Sentence Summary
Linux is an open-source, [[Unix]]-like operating system [[Kernel]] that serves as the foundation for a vast family of operating systems known as distributions (distros).
## 💡 Analogy
Linux is like the **engine of a car**. It's the powerful, core component that makes the car run, but it's not the entire car. Different manufacturers take this same powerful engine and build their own unique car models around it (**distributions** like [[Fedora]], Ubuntu, or Debian), each with a different body, interior, and dashboard (desktop environment and tools).
## 📜 History & Creator
The [[Linux Kernel]] was created by Finnish student **Linus Torvalds** in 1991. 
He announced the project on a Usenet newsgroup as a personal hobby, aiming to create a free and open-source alternative to the Unix operating systems. 
It was combined with the tools and utilities from the **[[GNU Project]]**, founded by Richard Stallman, to create a complete, functional operating system.
## 🔑 Core Philosophy & Design 
The Linux philosophy is inherited directly from [[Unix]] and can be summarized as "Everything is a file." 
- **Open Source:** 
	- The source code is freely available for anyone to view, modify, and distribute. This fosters a massive global community of contributors. 
- **Modularity:** 
	- The system is composed of many small, single-purpose tools that can be combined in powerful ways through the **[[CLI|command-line interface (CLI)]]**. 
- **The Kernel:** The [[Linux Kernel]] itself is **monolithic**, meaning it manages all the core OS functions (processes, memory, devices) in one large program.
## ⚙️ Key Details 
- **What it is:** 
	- A Unix-like operating system kernel and, by extension, the family of operating systems built around it. 
- **Why it exists:** 
	- To provide a free, open-source, and powerful [[_Operating Systems|operating system]] for a wide range of [[_Computer Hardware|hardware]], from servers and supercomputers to embedded devices. 
- **Key Components:** 
	- **The [[Linux Kernel]]:** The core of the OS. 
	- **[[Shell]]:** The command-line interface (e.g., `bash`). 
	- **Desktop Environment:** The graphical user interface (GUI) (e.g., GNOME, KDE). 
	- **[[Package Manager]]:** The system for installing and managing software (e.g., `DNF` in Fedora, `APT` in Debian/Ubuntu).
## 🔗 Connections & Implementations
- **My Personal Setup:** My primary workstation runs on [[Fedora|Fedora Workstation]]. 
- **Servers & Cloud:** Linux dominates the server, cloud computing, and supercomputing markets. 
- **Android:** The Android OS is built on top of a modified [[Linux Kernel]].
