# _Web Development_

## 📝 One-Sentence Summary
Web development is the process of building and maintaining websites and web applications, encompassing client-side (frontend), server-side (backend), and database technologies. 
## 🔗 Core Areas 
This note serves as the central hub for my web development studies, which are organized into three main areas: 
- **`01_Frontend/`**: Technologies that run in the user's browser to create the user interface and experience. 
- **`02_Backend/`**: Technologies that run on the server to handle logic, data processing, and databases. 
- **`03_Frameworks/`**: High-level tools and libraries that provide structure and efficiency for building complex applications.
