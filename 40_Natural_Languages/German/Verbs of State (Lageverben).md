# Verbs of State (Lageverben)

📝 **One-Sentence Summary**
Verbs of state describe an object's static, unchanging position and are the primary trigger for using the [[Dative Case]] with two-way prepositions to answer the question "Wo?" (Where?).

💡 **Core Rule & Analogy**
**The Rule:** When describing a static location, use a verb of state. This verb signals that any following two-way preposition must take the Dative case.

**Analogy:** Think of these as **"state-query" functions** (`isStanding()`, `isLying()`). They don't change data; they simply report the object's current positional state. This contrasts with "state-setting" functions (`placeItem()`, `hangItem()`), which imply action and will require the Accusative case.

⚙️ **Syntactical Structure**
These verbs are used to describe how an object is positioned.

| Verb | Meaning | Typically Used For... |
| :--- | :--- | :--- |
| **liegen** | to lie (down) | Objects in a horizontal position (a key, a book, a pen). |
| **stehen** | to stand | Objects with a flat base or in an upright position (a cup, a computer, a person). |
| **hängen** | to hang | Objects suspended from a surface (a picture on a wall, a lamp from the ceiling). |
| **sein** | to be | A general-purpose verb for existence or location. |
| **sitzen** | to sit | Primarily for people and animals. |

🚀 **Examples in Context**
-  Der Schlüssel **liegt** unter einem Blumentopf.  (The key **is lying** under a flowerpot.)
-  Der Blumentopf **steht** neben der Tür.  (The flowerpot **is standing** next to the door.)
-  Das Foto **hängt** an der Wand. (The picture **is hanging** on the wall.)

🔗 **Connections**
-   These verbs provide the context for using [[Two-Way Prepositions (Dative)]].
-   They are the counterparts to [[Verbs of Action (Direktionale Verben)]], which are used with the Accusative case.
-   Key verbs for individual notes: [[liegen]], [[stehen]], [[hängen]].
