# Passiv

## 📝 One-Sentence Summary
A grammatical voice where the subject of the sentence is the recipient of the action, rather than the performer.

## 💡 Core Rule & Analogy
**The "Focus Shift":** 
- **Aktiv:** "Der Student schreibt den Code." (Focus on *who* is doing it).
- **Passiv:** "Der Code wird geschrieben." (Focus on *what* is happening).
Imagine the system is an autonomous agent—we don't care who triggered the function, only that the function is being executed.

## ⚙️ Syntactical Structure
**Vorgangspassiv (Process):** Focuses on the action taking place.
> **werden + Partizip II**

**Zustandspassiv (State):** Focuses on the completed result.
> **sein + Partizip II**

| Tense      | Structure         | Example                        |
| :--------- | :---------------- | :----------------------------- |
| Präsens    | wird + P2         | Die Daten werden gesendet.     |
| Präteritum | wurde + P2        | Das System wurde aktualisiert. |
| Perfekt    | ist + P2 + worden | Der Fehler ist behoben worden. |

## 🚀 Examples in Context
1. **Cloud/DevOps:** "Der Docker-Container **wird** gestartet." (The container is being started.)
2. **Cybersecurity:** "Das Passwort **muss** geändert **werden**." (The password must be changed.)
3. **Distributed Systems:** "Die Nachrichten **wurden** über das Netzwerk **übertragen**." (The messages were transmitted via the network.)
