# Distributed Systems Vocabulary (Verteilte Systeme)

## 🏗️ Architecture & Structure (Architektur)
Terms related to the physical or logical layout of the system.

| English | German (Gender) | Context |
| :--- | :--- | :--- |
| **Architecture** | Die **Architektur** | *Client-Server-Architektur* |
| **Distributed System** | Das **verteilte System** | *Ein verteiltes System entwerfen* |
| **Node** | Der **Knoten** | *Jeder Knoten ist unabhängig* |
| **Interface** | Die **Schnittstelle** | *Die Schnittstelle definieren* |
| **Cluster** | Der **Cluster** | *Ein Cluster von Servern* |
| **Load Balancer** | Der **Lastverteiler** | *Der Lastverteiler regelt den Traffic* |

## ⚙️ Behavior & Metrics (Verhalten)
Terms related to how the system runs and performs.

| English | German (Gender) | Context |
| :--- | :--- | :--- |
| **Behavior** | Das **Verhalten** | *Das Verhalten zur Laufzeit* |
| **Throughput** | Der **Durchsatz** | *Hoher Durchsatz ist wichtig* |
| **Latency** | Die **Latenz** | *Niedrige Latenz garantieren* |
| **Scalability** | Die **Skalierbarkeit** | *Horizontale Skalierbarkeit* |
| **Fault Tolerance** | Die **Fehlertoleranz** | *Das System ist fehlertolerant* |
| **Availability** | Die **Verfügbarkeit** | *Hochverfügbarkeit (High Availability)* |
