# Daily Routine (Tagesablauf)

## 📝 One-Sentence Summary
High-frequency verbs and nouns describing the daily algorithm, focusing on "Separable Verbs" and "Movement."

## 💡 Tech Analogy
* **Separable Verbs:** Like a function call with arguments. `aufstehen` $\rightarrow$ `Ich stehe ... auf`. The prefix (`auf`) is pushed to the end of the stack.

## 🗃️ The Verb Database (Action)

| Infinitive | Perfekt (Past) | Helper | English | Context |
| :--- | :--- | :--- | :--- | :--- |
| **aufstehen** | aufgestanden | **sein** | to get up | Change of state (bed $\rightarrow$ floor) |
| **aufwachen** | aufgewacht | **sein** | to wake up | Eyes open |
| **einschlafen** | eingeschlafen | **sein** | to fall asleep | |
| **frühstücken** | gefrühstückt | haben | to breakfast | |
| **fahren** | gefahren | **sein** | to drive/ride | Commute (*zur Uni fahren*) |
| **gehen** | gegangen | **sein** | to go/walk | |
| **besuchen** | besucht | haben | to visit | *Eltern besuchen* |
| **stressen** | gestresst | haben | to stress | *Stress haben* |

## 🚀 Examples in Context
1.  **Morning:** Der Wecker **klingelt** um 6:30 Uhr.
2.  **Movement:** Ich **bin** um 7:30 Uhr zur Uni **gefahren**.
3.  **Evening:** Ich **bin** sofort **eingeschlafen**.
