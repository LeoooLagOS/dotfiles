# Linux Admin Vocab

## 📝 One-Sentence Summary
German terminology for system administration and command-line operations.

## ⚙️ Syntactical Structure
- **Der Befehl:** (The command) - *Welcher Befehl löscht die Datei?*
- **Das Verzeichnis:** (The directory) - *In welchem Verzeichnis bin ich?*
- **Ausführen:** (To execute/run) - *Ich führe das Programm aus.*
- **Beenden:** (To end/terminate) - *Beenden Sie den Prozess.*

## 🚀 Examples in Context
* "Ich muss das System **aktualisieren**." (I must update the system.)
* "Der **Hintergrundprozess** (Daemon) läuft noch." (The background process is still running.)
