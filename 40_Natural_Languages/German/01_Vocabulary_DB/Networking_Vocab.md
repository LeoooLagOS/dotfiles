# Networking Vocabulary

## 📝 One-Sentence Summary
Core technical terminology for computer networking and system administration.

## 💡 Core Rule & Analogy
Technical German often adopts English loanwords but applies German gender and articles.

## 🚀 Examples in Context
1. **Der Systemadministrator:** (The SysAdmin) 
	- *Der Systemadministrator wartet den Server.*
2. **Das Netzwerk:** (The Network) 
	- *Das Netzwerk ist langsam.*
3. **Die Dienstleistung:** (The Service/Duty) 
	- *Der Server bietet eine Dienstleistung an.*
4. **Aktualisieren:** (To update) 
	- *Ich muss das System aktualisieren.*
