# Advanced Collocations (Fixed Phrases)

## 📝 One-Sentence Summary
Collocations are words that statistically appear together; using a synonym often sounds "wrong" to a native ear even if the meaning is correct.

## ⚙️ The "Doomed" List (C2 Essentials)

| The Phrase | The Wrong Synonym | Context / Usage |
| :--- | :--- | :--- |
| **Doomed to failure** | *Destined* to failure | Projects/Plans that never had a chance. |
| **Diametrically opposed** | *Completely* opposed | Opinions/Arguments. |
| **Cautiously optimistic** | *Carefully* optimistic | Project status/Forecasts. |
| **Virtually impossible** | *Almost* impossible | Technical limitations. |
| **Foregone conclusion** | *Obvious* conclusion | A result that was certain before it happened. |
| **Glaring error** | *Big* error | A bug/mistake that is very obvious. |
| **Mitigate risk** | *Lower* risk | Professional standard. |

## 🚀 The "Verb-Noun" Bindings
* You don't *make* a crime → You **commit** a crime.
* You don't *say* an apology → You **tender** (formal) or **offer** an apology.
* You don't *close* a deal → You **seal** or **clinch** a deal.
* You don't *make* a theory → You **formulate** a theory.
