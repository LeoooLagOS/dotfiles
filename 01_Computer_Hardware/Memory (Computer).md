# Memory (Computer)

## 📝 One-Sentence Summary
In computing, memory refers to the physical devices used to store information for immediate use in a computer, primarily divided into fast, volatile types ([[RAM]]) and non-volatile types ([[ROM]]).

## 💡 Analogy
Computer memory is like the different parts of the **human brain's memory**. 
- **[[RAM|RAM (Random-Access Memory)]]** is your **short-term, conscious thought**. It's what you're actively thinking about right now. It's fast, but when you fall asleep (lose power), it's gone. 
- **[[ROM|ROM (Read-Only Memory)]]** is your **instinct or muscle memory**. It holds the basic, unchangeable instructions for how to function, like how to breathe. 
- **[[Storage Devices|Storage]]** (like an SSD) is your **long-term memory**. It holds all your knowledge and experiences that you can recall when needed.
## 🔑 Key Details
- **What it is:** 
	- The part of the computer that holds data and instructions that are actively being used by the [[CPU]]. It is also known as **primary storage**. 
- **Why it exists:** 
	- To provide the [[CPU]] with extremely fast access to information. Accessing data from memory is thousands of times faster than retrieving it from long-term [[Storage Devices]]. 
- **The Memory Hierarchy:** 
	- Memory is organized in a hierarchy based on speed and cost. At the top are small, ultra-fast **CPU registers** and **[[Cache|cache]]**, followed by the much larger main memory ([[RAM]]), and finally the slower, cheaper mass storage.

## 🔗 Connections & Implementations
- **Volatile Memory:** 
	- [[RAM|RAM (Random-Access Memory]] 
- **Non-Volatile Memory:** 
	- [[ROM|ROM (Read-Only Memory]] 
- **Cache Memory:** 
	- A small amount of extremely fast memory (typically [[SRAM]]) that acts as a buffer between the CPU and RAM.
