# RS232 (Recommended Standard 232)

## 📝 One-Sentence Summary
A standard for serial data transmission between a DTE (Computer) and a DCE (Modem/Hardware) using specific voltage levels.

## 💡 Analogy
A very narrow one-lane bridge where cars (Bits) must travel in a single file line at a pre-agreed speed (Baud Rate).

## 🔑 Key Details
- **What it is:** The physical layer standard for serial ports.
- **Wiring Logic (Crossover):** 
	- **TxD** (Transmit) -> **RxD** (Receive)
	- **DTR** (Data Terminal Ready) -> **DSR** (Data Set Ready)
- **Distance vs Speed:**
	- 9600 Baud = ~30 Meters.
	- 300 Baud = ~300 Meters.
- **[[VPE|VPE (Virtual Programming Environments)]]:** Red Term, Hercules, HyperTerminal.

## 🔗 Connections & Implementations
- Wireless variation via [[Bluetooth]].
- Industrial variation via [[Modbus]].
