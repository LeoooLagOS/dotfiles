# _Windows_

## 📝 One-Sentence Summary
Windows is a family of proprietary graphical [[_Operating Systems]] developed and marketed by Microsoft, which became the dominant OS for personal computers worldwide.
## 💡 Analogy
Windows is like a **pre-built, all-in-one home appliance**, like a smart refrigerator. It comes as a complete, polished product with a user-friendly graphical interface (the screen on the fridge door), and it's designed to be easy for the average person to use right out of the box. You don't get to see or modify its internal wiring (proprietary source code).
## 📜 History & Creator
The first version of Windows, Windows 1.0, was released in 1985 by **Microsoft**, founded by Bill Gates and Paul Allen. It began as a graphical [[Shell]] that ran on top of their text-based MS-DOS operating system. 
The major breakthrough came with **Windows 95**, which integrated the OS and the graphical interface and introduced features like the Start menu and taskbar, setting the standard for personal computing for decades.
## 🔑 Core Philosophy & Design 
The core philosophy of Windows is **user-friendliness and backward compatibility**. 
- **Proprietary:** 
	- The source code is closed and owned by Microsoft. 
- **Graphical User Interface (GUI) First:** 
	- The primary way to interact with the OS is through its graphical interface, making it accessible to non-technical users. 
- **Backward Compatibility:** 
	- A major design goal has always been to ensure that software written for older versions of Windows will continue to run on newer versions.
## ⚙️ Key Details 
- **What it is:** 
	- A family of proprietary operating systems for personal computers, servers, and other devices. 
- **Why it exists:** 
	- To provide a user-friendly, graphical operating system for the mass-market personal computer. 
- **Key Components:** 
	- **[[Windows NT Kernel]]:** 
		- The [[Hybrid Kernel|hybrid kernel]] that forms the core of all modern Windows versions. 
	- **Windows Shell:** 
		- The graphical interface, including the desktop, taskbar, and Start menu. 
	- **Windows API:** 
		- The set of application programming interfaces that developers use to write software for Windows. 
	- **Registry:** 
		- A hierarchical database that stores low-level settings for the OS and applications.
## 🔗 Connections & Implementations
-   **Command Line:** 
	- While GUI-focused, Windows has powerful command-line interfaces like **[[PowerShell]]** and the **[[Windows Subsystem for Linux (WSL)]]**.
